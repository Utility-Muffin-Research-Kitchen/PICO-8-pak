# Artwork provenance

`PICO8-photo.png` is a ChatGPT-generated illustration supplied for this
integration on September 12, 2026. It depicts a fictional PICO-8 console and
controller in a photographic style. Reference-image details were not supplied.

The original 1349x1166 RGBA PNG is preserved unchanged in the private
`umrk-assets` repository at `Systems/ICONS/PICO8.png`. This runtime copy fits
the complete image, without cropping or stretching, onto a transparent
384x384 canvas. It was scaled with macOS AppKit high-quality interpolation;
non-rendering PNG metadata was removed.

No exclusive rights are claimed in the generated illustration. PICO-8 names
and marks belong to their respective rights holders and identify the platform.
This is not official Lexaloffle artwork or part of the purchased runtime.

Leaf's built-in photographic system set uses the same illustration at 70% of
this size within its own 384x384 canvas, matching neighboring Games artwork.
The pak keeps this larger framing for the Apps entry. PICO-8 remains a built-in system, so the
pak adds its native core without replacing the system definition or its artwork.
